# 📚 Library Management System

A simple library management system built with C# using Object-Oriented Programming (OOP) concepts.

## 🌟 Features

### For Librarians
- Login with name and age
- Add new books to the library  (A)
- Remove books from the library  (R)
- Display all available books    (D)

### For Normal Users
- Login with name and age
- Borrow books from the library  (B)
- View borrowed books    (D)
- Display user card with borrowing status (S)

## 🛠 Technologies Used

- **Programming Language**: C#
- **Application Type**: Console Application
- **Paradigm**: Object-Oriented Programming (Inheritance, Encapsulation, Polymorphism)
- **Framework**: .NET


### Prerequisites
- [Visual Studio](https://visualstudio.microsoft.com/) or [Visual Studio Code](https://code.visualstudio.com/)
- .NET SDK
